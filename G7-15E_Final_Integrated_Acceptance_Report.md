## 1. Runtime Lifecycle Verification (E1)

### Mixed-worker artifact lookup — bug found and fixed

**The condition `this.closed || this.computers.size === 0` had a gap:**

When some workers are stopped (removed from `this.computers` by `stopWorker` but kept in `this.workers` for disk access) and others are still running (still in `this.computers`), `this.computers.size > 0` → the live path fires → iterates `this.computers` only → **misses the stopped workers' artifacts**.

**Fix (G7-15E):** Unified the live and disk paths. `listArtifacts()` now iterates `this.workers` (which has ALL workers). For each worker:
- If the computer is still in `this.computers` → use the live HTTP API.
- If the computer is NOT in `this.computers` (stopped) → read from disk via `workspaceDir`.

The closed-adapter shortcut (`if (this.closed)`) still goes straight to `listArtifactsFromDisk()` (all computers are stopped at that point). The deduplication check `out.some(...)` prevents double-counting when both paths see the same file.

**Changed file:** `src/runtime/openbot/adapter.ts` — `listArtifacts()` method rewritten (+50/-20 lines). No frozen-contract changes. No new dependencies.
