# Temperature Converter

A simple web application for converting between Celsius and Fahrenheit.

## Running the Application

1. Start the application:
   ```bash
   npm start
   ```
2. Open your browser and navigate to `http://localhost:3000` (or the URL shown in the terminal).

## Running Tests

To run the automated tests:

```bash
npm test
```

The tests verify the correctness of the temperature conversion formulas.
